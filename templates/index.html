PHILRICE FORECASTING TOOL

Standard Work Time Forecasting

Forecast weekly % Standard Work Time using chronological 80/20 validation and multiple trend- and fluctuation-capable models.

Raw RMSE uses the stored fractional scale: 0.05 equals 5 percentage points. No scaling or normalization is applied.

1. Prepare and upload data

Required columns: Employee, Week Start, % Standard Work Time. Use one row per employee per week and at least 12 consecutive weeks.

Values above 100% are allowed. Week Start dates must be exactly 7 days apart for each employee.

Results are still produced weekly. For example, 12 months produces approximately 52 weekly forecast points.
